Modular Activation & Master Controls

Surface Explorer features a modular control system designed for maximum flexibility. This allows users to control individual components independently or use a global command to synchronize the entire environment.

 

Individual Component Controls

Each functional module has its own dedicated activation and deactivation methods:

  • Surfaces & t_Motions: These can be activated using the Run button in the Equations Dock (which applies the equations and starts their t animation without touching the other modules), the Run Parametric or Run Implicit buttons in the Script Dock, or by loading a Preset.
  • Textures: Managed primarily through the Render Dock and the Script Dock. Textures can also be created directly from the Ray Marching tab of the Equations Dock.
    • Activation: Use the Run Parametric Texture or Run Background Texture buttons in the Script Dock, or the Run button in the Ray Marching tab of the Equations Dock. The selection between modes (Base/Phong for geometry vs. Background for environment) is handled in the Render Dock.
    • Deactivation: Use the checkbox located in the Render Dock to disable active textures.
  • Audio (Sounds): Sound scripts are triggered by clicking Run Sound in the Script Dock or through Presets. To halt playback, use the Stop Sound button in the Script Dock or the global STOP button.

 

START-STOP

The master START-STOP button in the Status Bar provides synchronized control over the entire scene:

  • Global START: Simultaneously triggers all loaded modules — parametric equations and their t animations included (e.g., starting geometric animations and audio playback at once). If the equations module is the only one loaded, START activates that module alone.
  • Global STOP: Immediately deactivates all currently running components across all modules.
  • Individual Controls: Each animation component can also be started or stopped independently using the local Run (such as the Run button in the Equations Dock for parametric equations), Stop, Departure, and Stop buttons found in their respective panels, or by clicking the corresponding item directly in the Library Dock. The local buttons act only on their own module, while the master button acts on all of them.
