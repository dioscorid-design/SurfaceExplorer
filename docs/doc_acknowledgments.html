Shadertoy & Procedural Textures

Several procedural texture presets included in the Library are adapted from shaders originally created by the talented community at Shadertoy (shadertoy.com). Unless otherwise stated, these specific scripts are distributed under the Creative Commons Attribution-NonCommercial-ShareAlike 3.0 Unported License (CC BY-NC-SA 3.0).
Full credits, including the original author's name and a link to the source shader, can be found in the commented header of each respective texture script.
