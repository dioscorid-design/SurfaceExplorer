Videos

Recorded from the application with the built-in video export

No videos yet.

To add one: run docs/tools/make-preview.sh <video> <nome> <secondo> — it writes the clip and its poster into docs/media/. Then upload the full video to YouTube, uncomment the template block in this file (see the HTML comment above), fill in name and link, and push.

Why previews. The clips on this page are short silent loops served directly by GitHub Pages, which suits a few seconds of video but not a long recording: the file is downloaded whole rather than streamed. Each preview links to the full-length, high-resolution version on YouTube, so the page stays light and the complete render is still one click away.
